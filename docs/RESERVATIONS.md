# 在线预约

客人在 `/book.html` 预约餐桌（德/英/中三语）。菜单右上角的日历按钮也会打开这个页面；扫桌码进菜单的客人已经在店里，所以看不到这个按钮。

## 开启

管理台 → 预约 → 在线预约设置：

1. 打开「开放在线预约」。
2. **可预约时段**：每段填第一个和最后一个可预约的时间，例如午餐 11:30–13:30、晚餐 17:30–21:00。可以只选某几天。
3. **可选时间间隔**：15、30 或 60 分钟。
4. **每桌保留**：一次用餐占多久，默认 120 分钟。
5. **预约可用座位数**：同一时间最多有多少位预约客人在店里。
6. **在线预约最多人数**：再多的客人需要打电话。
7. **至少提前 / 最多提前**：例如至少提前 60 分钟、最多提前 60 天。
8. **不接受预约的日期**：休息日、包场。
9. 保存后，复制「预约页面链接」，放到官网、Google 地图、Instagram 上。

## 在线选座

在「在线选座：可预约的餐桌」里列出客人可以选的桌和每桌座位数（可以从桌台一键导入，再改座位数）。

- 列了餐桌：客人先选时间再选桌。座位不够的桌、这段时间已被订的桌都不能选。同一张桌在一次用餐时长内只能被订一次。
- 不列餐桌：客人只订座位，按「预约可用座位数」算容量，到店再安排桌子。

## 防恶意预约

- 在线预约必须用顾客账户登录（和菜单的顾客账户是同一个）。
- **每人最多同时有几个未来预约**（默认 2）和 **每人每天最多预约几次**（默认 1）：同一个账户按账户算；同一个电话号码按号码算，写法不同也能认出来（+43 / 0043 / 空格）。所以换个账户、用同一个号码也绕不过去。
- **未到几次后停止在线预约**（默认 2，0 = 不限制）：客人近半年内有这么多次被标为「未到」，就不能再在线预约，页面会请他打电话。把他的某次预约改回「已完成」就解除了。
- 同一个网络地址每分钟最多提交 60 次。

## 日常操作

- **按天**：看当天的预约；可以确认、拒绝、入座（填桌号）、完成、标记未到、取消，也可以登记电话预约。电话预约不受上面的限制。
- **预约单据**：跨日期查询，按预约号、姓名、电话、邮箱搜索，按状态筛选；点「预约单据」查看完整记录（账户、来源、下单时间、未到次数），可以打印，也可以导出 CSV。
- **POS 桌台**：顶部是今天的预约，可以一键入座或标记未到。已经安排了桌的预约，会在那张桌上显示预约时间。

## 个人数据

- 用餐日期过后 30 天，客人的姓名、电话、邮箱、备注自动清除，只保留人数和结果（用于统计）。
- 客人删除账户后，他未来的预约自动取消，所有预约的联系方式被清除。
- 客人「下载我的数据」时，导出的数据里包含他的预约。
- 店长可以在预约单据里彻底删除某条预约，用于客人要求删除数据的情况。
- 目前不发确认邮件或短信：客人在页面上看到预约号和专用链接，也能在「我的预约」里查看。以后要发邮件或短信，需要一个发信服务（例如 Brevo、Resend）的账户。
